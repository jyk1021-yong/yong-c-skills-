# 스토리보드: 쇼츠 1편 스쿼트 (약 46초, 세로 9:16)

참고 영상(@urami_tips 쇼츠, 46초)의 구성을 따르되, 캐릭터와 내용은 우리 것으로 만듭니다.
참고 영상의 시간은 1초 간격 캡처를 보고 추정한 값입니다.

## 참고 영상 구성 요약

| 시간 | 장면 | 자막 (한 단어씩) |
|------|------|------------------|
| 0~10초 | 바닥 포즈에서 시작, 일어나는 동작 | 베어 / 30초씩 / 버티면 / 일어날까요 |
| 10~20초 | 일어서기, 잘못된 자세(X 표시) → 올바른 자세 | 버틸 / 없습니다 / 엎드려 |
| 20~30초 | 부위 확대, 아픈 곳에 빨간 빛 | 떨립니다 / 2주차 카드 |
| 30~40초 | 척추·갈비뼈 X-ray, 주황 빛 | 바닥에 / 척추를 / 전부 |
| 40~46초 | 팔짱, 복부에 빛, 엄지 척 마무리 | 단단해지고 / 방금 / 하셨습니다 |

공통 특징: 큰 한글 제목 카드, 장면마다 확대와 전신이 번갈아 나옴, X-ray에는 뼈와 빛 효과가 있음.

## 우리 1편 장면표

## 장면별 세부 메모

- **3번 (잘못된 자세)**: 무릎이 발끝을 넘고 상체가 과하게 앞으로 쏠린 모습. 자세 값을 바꿔 만듭니다. 설명 글은 의학적 진단처럼 쓰지 않습니다.
- **5번 (올바른 자세)**: 이 장면이 가장 중요합니다. 프로토타입 동작을 그대로 녹화해 쓸 수 있습니다.
- **7번 (X-ray)**: 참고 영상처럼 뼈와 빛이 필요합니다. 현재 프로토타입에는 뼈가 없으므로 골반과 대퇴골 모양을 새로 만들어야 합니다. 이 장면은 가장 많은 작업이 필요합니다.
- **색 규칙**: 둔근 파랑, 대퇴사두 빨강, 햄스트링 주황, 종아리 초록은 프로토타입과 같게 맞춥니다.

## 제작 순서 제안

1. 프로토타입 장면 5번 녹화 (가장 빨리 확인 가능)
2. 장면 3, 6번 확대 카메라 추가
3. 장면 7번 X-ray용 뼈 모델 제작
4. 장면 1, 4, 8번 정지 이미지 제작 (AI 이미지 또는 프로토타입 캡처)
5. 편집 툴에서 자막, 제목 카드, 엔딩 카드 붙이기

## 확인 필요

- 장면 1, 8번을 AI 이미지로 만들지, 프로토타입 캡처로 갈지
- X-ray 뼈 모델을 직접 만들지, 외부 파일을 쓸지
